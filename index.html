☁️ Synchronisation Cloud

Connectez Firebase Firestore pour partager les données en temps réel entre plusieurs appareils et utilisateurs.

1
Allez sur console.firebase.google.com → Créer un projet
2
Ajoutez une app Web (bouton </>) → copiez la config
3
Activez Firestore Database en mode Test
4
Collez la config Firebase ci-dessous (objet firebaseConfig)

⚠️ En mode local, les données restent dans ce navigateur uniquement.
